# Project Pop-up Full Screen

## Structure

```text
Project Pop-up
├── Navigation
├── Header / Hero
├── Overview
├── Dynamic Content Sections
├── Outcomes / Impact
└── Footer / CTA
```

---

## 0. Navigation

**Detail elements:**

- Back button on the left
- Close button on the right

**Requirements:**

- Press `Esc` to close
- Click the Back button to close the pop-up
- Click the Close button to close the pop-up

---

## 1. Header / Hero

**Detail elements:**

- Project title
- Role
- Short description (impact-focused)
- Tags
- Timeline (optional)
- Close / Back button

---

## 2. Overview

- Short summary (what + why)
- Your responsibility

---

## 3. Dynamic Content Sections

This section changes based on the project type while keeping a shared reading pattern.

### Example types

### AI Product

- Problem
- AI approach (training / logic)
- Validation
- Output improvement

### Fintech / Banking

- Business problem
- User flow
- Constraints (regulation)
- Solution

### System / Enterprise

- Workflow complexity
- System design
- UX decisions

---

## 4. Outcomes / Impact

- Key outcomes / impact

---

## 5. Footer / CTA

- Next project CTA (optional)
