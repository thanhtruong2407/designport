UX/UI System (Human Branch)

A preset-based interaction system that gives users editable text shadow controls and real-time canvas preview, making the output more predictable and controllable.

01

Challenge

Too many parameters, low confidence

Text shadow requires multiple parameters such as offset, opacity, color, and blur. For non-designers, this makes the feature difficult to understand and use.

Users struggle to predict the final result and make confident decisions.

02

Approach

Preset-based interaction

Instead of showing all parameters by default, the system provides predefined presets: None, Minimal, Soft, Hard, and Glow.

Users can

  • Select a preset
  • Preview the result instantly
  • Customize values when needed

This keeps the experience simple while still supporting advanced control.

03

Preset System Design

From visual decisions to system rules

Text shadow behavior is converted into structured, rule-based presets. Each preset follows predefined values and scales across different contexts.

This creates consistent and predictable outputs.

04

UI Design

Simple and predictable interactions

Users can apply presets directly on the canvas and preview results in real time.

The preset list remains the primary interaction model, while detailed parameters are only shown during customization.

This keeps the default workflow lightweight and easy to use.

05

Preset Testing & Validation

Validating rendering accuracy

Testing focused on ensuring that text shadow rendered correctly based on the defined preset rules.

Manual testing and AI output validation were conducted across multiple iterations to improve consistency and accuracy.

From visual patterns to computable rules

Core Concept

Text shadow is treated as a rule-based system, not a fixed visual style.

The goal is to convert subjective visual decisions into structured logic for both UX and AI consistency.

Core Idea & Outcomes

Core Idea: Transform visual intuition into scalable, rule-based presets.

Outcomes: Simplified selection, consistent output, and a shared language between UX and AI.

Preset & Formula System

Presets: Minimal for subtle depth, Soft for gentle shadow, Hard for strong emphasis, and Glow for dramatic effect.

Each preset represents a specific visual intention.

Formula System: Shadow values are calculated based on font size and font weight.

Example logic: Offset scales with font size, blur adjusts based on visual density, and opacity stays controlled for readability.

This ensures consistent rendering across different contexts.

Behavior System

Shadow values update dynamically when users change presets or modify text properties.

Flow: User updates → System recalculates → Shadow updates.

This maintains visual consistency automatically.

System Impact

Text shadow affects multiple typography settings across the system.

Existing typography features were reviewed to ensure consistent integration and avoid fragmented behavior.

Without a structured preset system, text shadow becomes inconsistent and difficult to scale.

Translating systems into intuitive interactions

Interaction Design

The UI translates the preset system into a simple and predictable interaction model.

Users can: apply presets directly on the canvas, preview results instantly, and understand the current selection through clear states and feedback.

This makes complex visual logic easier to use and control.

System Integration

The UI aligns text shadow behavior with: typography settings, theme configuration, and existing text features.

This keeps the feature consistent across the product.

Visual Validation

Text shadow was tested on: light backgrounds, dark backgrounds, and image backgrounds.

Validation focused on: readability, visual consistency, and reducing visual noise.

The goal was to ensure reliable results across real usage scenarios.

A well-designed UI is not only about interaction, but about ensuring that the output works in real-world contexts.
